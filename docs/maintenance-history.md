# Maintenance history

The public project is an intentionally curated continuation of a private
research prototype.

1. A domain prototype explored hierarchical control for multi-user VR edge
   rendering.
2. Training work exposed allocation, logging, and recovery costs in long
   rollouts.
3. Preallocated observations, rewards, and rollout arrays were extracted as
   reusable systems techniques.
4. The extracted runtime was generalized to serial, same-process vector, and
   spawned multi-process Gymnasium execution.
5. A synthetic VR workload and native-Windows benchmark were added so the
   component can be evaluated without private data.

Detailed debugging journals, raw experiments, private paths, model weights,
and intermediate research documents are deliberately not part of the public
history.
